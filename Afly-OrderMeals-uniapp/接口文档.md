# 点餐小程序接口文档

---

## 基础信息

- **Base URL**: `/front`
- **积分商城 Base URL**: `/api/integral`
- **通用响应格式**:
```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```
- **分页参数**: `page` (默认1), `pageSize` (默认20)

---

## 一、认证模块 `/front/auth`

### 1.1 微信登录
```
POST /front/auth/wx/login
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | 微信授权code |

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "token": "xxx",
    "openid": "xxx"
  }
}
```

### 1.2 微信获取手机号
```
POST /front/auth/wx/phone
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| openid | string | 是 | 微信openid |
| phoneCode | string | 是 | 手机号验证码 |

### 1.3 支付宝登录
```
POST /front/auth/ali/login
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| authCode | string | 是 | 支付宝授权code |

### 1.4 支付宝获取手机号
```
POST /front/auth/ali/phone
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| authCode | string | 是 | 支付宝授权code |

### 1.5 短信发送
```
POST /front/auth/app/sms/send
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mobile | string | 是 | 手机号 |

### 1.6 短信登录
```
POST /front/auth/app/sms/login
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mobile | string | 是 | 手机号 |
| code | string | 是 | 验证码 |

### 1.7 模拟手机号登录（调试用）
```
POST /front/auth/mock/phone
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mobile | string | 是 | 手机号 |

### 1.8 获取用户信息
```
GET /front/auth/profile
```
**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": 1,
    "nickname": "用户123",
    "mobile": "138xxxxxxx",
    "avatar": "https://xxx.com/avatar.png",
    "balance": 100.00,
    "point": 500,
    "companyVerified": true,
    "companyDeptName": "技术部"
  }
}
```

### 1.9 更新用户信息
```
POST /front/auth/profile/update
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| nickname | string | 否 | 昵称 |
| avatar | string | 否 | 头像URL |

### 1.10 退出登录
```
POST /front/auth/logout
```

## 三、订单模块 `/front/order`

### 3.1 获取店铺信息
```
GET /front/order/shop
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| aid | number | 是 | 店铺ID |

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": 1,
    "name": "粮兴坊",
    "deliveryEnable": 1
  }
}
```

### 3.2 获取菜单
```
GET /front/order/menu
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| aid | number | 是 | 店铺ID |

### 3.3 创建购物车
```
POST /front/order/cart/create
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| aid | number | 是 | 店铺ID |
| type | number | 是 | 订单类型：1=堂食 2=自取 3=外卖 |

### 3.4 检查购物车是否存在
```
GET /front/order/cart/has
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| aid | number | 是 | 店铺ID |

### 3.5 添加餐品到购物车
```
POST /front/order/cart/dishAdd
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | number | 是 | 订单ID |
| dishId | number | 是 | 餐品ID |

### 3.6 增加餐品数量
```
POST /front/order/cart/dishInc
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | number | 是 | 购物车项ID |

### 3.7 减少餐品数量
```
POST /front/order/cart/dishDec
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | number | 是 | 购物车项ID |

### 3.8 删除购物车项
```
POST /front/order/cart/dishDel
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | number | 是 | 购物车项ID |

### 3.9 清空购物车
```
POST /front/order/cart/toEmpty
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | number | 是 | 订单ID |

### 3.10 提交订单
```
POST /front/order/submit
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | number | 是 | 订单ID |
| addressId | number | 否 | 地址ID（外卖必填） |
| remark | string | 否 | 备注 |
| couponId | number | 否 | 优惠券ID |

### 3.11 获取订单列表
```
GET /front/order/list
```
**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": 1,
      "orderNo": "ORD202406010001",
      "status": 1,
      "totalPrice": 99.00,
      "createTime": "2024-06-01 10:00:00"
    }
  ]
}
```

### 3.12 获取订单详情
```
GET /front/order/detail
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | number | 是 | 订单ID |

### 3.13 取消订单
```
POST /front/order/cancel
```
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | number | 是 | 订单ID |
| reason | string | 否 | 取消原因 |
